# 칠판 공지판

교실 칠판(TV)에 띄워 두는 **바탕화면 알림판**입니다.

- 바탕화면에 붙어 있습니다. 다른 프로그램을 띄우면 가려지고, 바탕화면을 보면 다시 보입니다.
  `Win + D`(바탕화면 보기)를 눌러도 사라지지 않습니다.
- 우유 가져오는 순서, 오늘 할 일, 잊지 말 것 등을 적어 둡니다.
- 내용은 `공지.txt` 파일 하나로 관리합니다. 메모장으로 고치고 저장하면 몇 초 안에 화면이 바뀝니다.
- 우유 당번은 순서와 시작일만 적어 두면 평일마다 자동으로 넘어갑니다. (주말·공휴일 제외)

## 1. 설치 (처음 한 번)

1. [python.org](https://www.python.org/downloads/)에서 Python 3(3.8 이상)을 설치합니다. 버전은 첫 화면의 큰 버튼 그대로 받으면 됩니다.
   - 설치 파일에 **"Add python.exe to PATH"** 체크 칸이 보이면 꼭 체크합니다.
   - 대신 검은 창(Python install manager)이 뜨면서 `[y/N]`으로 묻는 새 설치 도우미가 나오면, 모두 `y`를 입력하고 Enter 합니다.
2. 명령 프롬프트에서 `py --version`을 쳐서 버전 숫자가 나오는지 확인합니다.
3. 이 폴더를 통째로 학교 컴퓨터에 복사합니다. (예: `문서\칠판공지판`)

추가로 설치할 라이브러리는 없습니다.

## 2. 실행

`공지판_실행.bat`을 더블클릭합니다.
처음 실행하면 `공지.txt`가 자동으로 만들어지고, 화면 오른쪽 위에 알림판이 나타납니다.

| 파일 | 하는 일 |
| --- | --- |
| `공지판_실행.bat` | 알림판 켜기 |
| `공지.txt` | 알림판 내용·모양 설정 (메모장으로 편집) |
| `자동실행_등록.bat` | 컴퓨터를 켤 때 자동으로 알림판 켜기 |
| `자동실행_해제.bat` | 자동 실행 끄기 |
| `문제확인_보통창으로_실행.bat` | 바탕화면에 안 붙고 보통 창으로 띄우기 (문제 확인용) |
| `notice_board.py` | 프로그램 본체 |

알림판 오른쪽 아래의 작은 글자 버튼:

- **편집**: `공지.txt`를 메모장으로 엽니다.
- **새로고침**: 파일을 다시 읽습니다. (보통은 저장하면 자동으로 됩니다)
- **닫기**: 알림판을 끕니다.

## 3. 내용 고치기 (`공지.txt`)

```text
[제목]
5학년 4반 알림판

[우유 순서]
1모둠
2모둠
3모둠

[우유 시작일]
2026-09-01

[우유 쉬는 날]
2026-10-03
2026-10-09

[오늘 할 일]
- 알림장 쓰기
- 급식 후 양치하기

[잊지 말기]
! 9월 5일(금)까지 현장체험학습 신청서 내기
- 목요일 체육복 챙기기
```

규칙:

- `[대괄호]`는 구역 이름입니다. `[준비물]`, `[이번 주 청소]`처럼 **마음대로 추가**하면 그대로 화면에 나옵니다.
- `#`으로 시작하는 줄은 설명이라서 화면에 나오지 않습니다.
- 줄 앞에 `!`를 붙이면 강조색으로 굵게 표시됩니다.
- `[우유 순서]`는 위에서부터 차례대로, 평일마다 한 칸씩 넘어갑니다.
  `[우유 시작일]`에 맨 위 당번이 시작하고, `[우유 쉬는 날]`에 적은 날은 순서가 넘어가지 않습니다.
- 우유 당번이 필요 없으면 `[우유 순서]` 구역을 비우거나 지우면 됩니다.

## 4. 모양 바꾸기 (`공지.txt`의 `[창]` 구역)

```text
[창]
위치 = 오른쪽 위      # 오른쪽 위 / 오른쪽 아래 / 왼쪽 위 / 왼쪽 아래 / 가운데 / 1200,80
너비 = 560
높이 = 자동           # 자동 또는 숫자
글자크기 = 22
모니터 = 1            # 1 = 주 모니터, 2 = 두 번째 모니터
배경색 = #1f2937
글자색 = #f9fafb
보조색 = #cbd5e1
강조색 = #fbbf24
투명도 = 1            # 0.2 ~ 1
```

칠판 TV에서 멀리서도 보이게 하려면 `글자크기`를 28~36 정도로 올리고 `너비`를 넓히면 됩니다.

## 5. 자주 묻는 문제

- **더블클릭해도 아무것도 안 뜬다**
  폴더에 `공지판_오류.txt`가 생겼는지 봅니다. 파일 안에 원인이 적혀 있습니다.
  Python이 설치되지 않았거나, 명령 프롬프트에서 `py --version`이 안 되는 경우가 가장 많습니다.
- **알림판이 바탕화면 아이콘에 가려진다 / Win+D 하면 사라진다**
  윈도우 버전에 따라 바탕화면 창 구조가 달라서 붙이기에 실패한 경우입니다.
  이때는 자동으로 "항상 맨 아래 창" 방식으로 바뀌어 동작합니다. 다른 창에는 여전히 가려지고, 바탕화면을 보면 보입니다.
- **알림판이 아이콘과 겹친다**
  `[창]`의 `위치`를 바꾸거나, 바탕화면 아이콘을 다른 쪽으로 옮깁니다.
- **글자가 깨진다**
  `공지.txt`를 메모장에서 "다른 이름으로 저장"할 때 인코딩을 **UTF-8**로 저장합니다.

## 6. 동작 원리 (참고)

Python 표준 라이브러리(tkinter, ctypes)만 사용합니다.
윈도우에서는 바탕화면 아이콘을 담고 있는 창(`Progman` 또는 `WorkerW`)을 찾아 알림판 창을 그 자식으로 붙입니다.
그래서 다른 창보다는 아래에, 바탕화면 아이콘보다는 위에 놓이고, 바탕화면 보기를 눌러도 남아 있습니다.
