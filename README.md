# 우리 반 교실 관리 사이트

전자칠판·교사 PC·폰 어디서 열어도 같은 기록이 보이는 교실 관리 사이트입니다.

| 탭 | 하는 일 |
| --- | --- |
| **과제 체크** | 과제마다 학생 이름 칸이 있어요. 이름을 터치하면 완료(초록), 다시 터치하면 해제. 과제는 여러 개 만들 수 있어요. |
| **번호 뽑기** | 학생이 자기 이름을 누르면 남은 번호 중 하나가 뽑혀요(2초 연출). 결과는 자동으로 기록되고, 같은 번호·같은 학생 중복은 막혀요. |
| **수학 확인** | 분수 연산 마스터에서 **이전 등교일**에 수학을 안 한 학생 이름을 보여 줘요. |
| **우리 반** | 학생 명단(붙여넣기·분수 연산 마스터에서 가져오기), 설정, 엑셀(CSV) 내보내기, 백업. |

- 기록은 **Firebase(Firestore)** 에 저장돼요. 칠판에서 누르면 폰에도 바로 바뀌어요.
- 인터넷이 잠깐 끊겨도 과제 체크는 기기에 저장해 두었다가 연결되면 자동으로 올라가요. (번호 뽑기는 연결되어 있어야 해요)
- 사이트는 **Vercel** 에 올려요. 둘 다 무료 요금제로 충분해요.

> 잠금(비밀번호)이 없어서 사이트 주소를 아는 사람은 누구나 보고 고칠 수 있어요. 주소를 학생·외부에 공유하지 마세요.

## 1. 처음 설정 (한 번만)

### 1-1. Firebase 프로젝트 만들기

**분수 연산 마스터와 다른 새 프로젝트**를 만드세요. 같은 프로젝트를 쓰면 그쪽 무료 한도를 다 썼을 때 이 사이트도 멈춰요.

1. <https://console.firebase.google.com> → **프로젝트 추가** → 이름 예: `uriban-5-4` → Google 애널리틱스는 꺼도 돼요 → 만들기
2. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
3. Firestore 화면 위쪽 **규칙** 탭 → 내용을 모두 지우고, 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣기 → **게시**
4. 왼쪽 위 톱니바퀴 **프로젝트 설정** → 아래쪽 **내 앱** → 웹 아이콘 `</>` → 앱 닉네임 아무거나 → **앱 등록**
   (Firebase 호스팅 체크는 하지 마세요)
5. 화면에 나온 `const firebaseConfig = { ... }` 안의 값 6개를 복사해 둡니다.

### 1-2. 설정값을 사이트에 넣기

1. GitHub 저장소에서 [`public/js/firebase-config.js`](public/js/firebase-config.js) 를 열고 연필(✏️) 버튼
2. 빈 따옴표 `''` 안에 복사한 값을 하나씩 넣기

   ```js
   export const firebaseConfig = {
     apiKey: 'AIza...',
     authDomain: 'uriban-5-4.firebaseapp.com',
     projectId: 'uriban-5-4',
     storageBucket: 'uriban-5-4.appspot.com',
     messagingSenderId: '1234567890',
     appId: '1:1234567890:web:abcdef',
   };
   ```
3. **Commit changes** 로 저장

이 값들은 원래 웹사이트에 공개되는 값이라 GitHub 에 올려도 괜찮아요.

### 1-3. Vercel 에 올리기

1. <https://vercel.com> → **Continue with GitHub** 로 로그인
2. **Add New… → Project** → `blankchatbot` 저장소 옆 **Import**
3. Framework Preset 은 **Other** 그대로, 다른 칸은 건드리지 말고 **Deploy**
4. 1분쯤 뒤 나오는 주소(예: `https://blankchatbot-xxxx.vercel.app`)가 우리 반 사이트예요.
5. 전자칠판·PC·폰 브라우저에서 이 주소를 **즐겨찾기**

이후에는 GitHub 에 바뀐 내용이 올라가면 Vercel 이 자동으로 다시 올려요.

### 1-4. 사이트에서 반 설정

1. **우리 반** 탭
   - 학생 명단: `여러 명 한꺼번에 붙여넣기`(엑셀에서 번호·이름 두 칸 복사) 또는 `분수 연산 마스터에서 명단 가져오기` → **명단 저장**
   - 설정: 반 이름, 분수 연산 마스터 반 코드(교사 화면 위쪽 6글자), 등교 안 하는 날 → **설정 저장**
2. **과제 체크** 탭에서 `+ 과제 만들기`

## 2. 쓰는 법

### 과제 체크
- 위쪽 버튼으로 과제를 고르고, 이름 칸을 터치하면 완료 / 다시 터치하면 해제
- 아래 줄에 "아직: ○번 ○○○ …" 이 보여요
- **💾 저장하고 새 과제**: 지금 과제를 저장(지난 기록으로 보냄)하고 바로 다음 과제를 만들어요
- **📋 지난 기록**: 저장한 과제를 날짜별로 봐요(완료 수, 아직 안 한 학생). 눌러서 들어가면 늦게 낸 학생을 그 안에서 체크할 수 있고, `다시 열기`로 체크 화면에 되돌릴 수도 있어요
- `⋯` 버튼: 이름 바꾸기, 저장만 하기, 체크 모두 지우기, 과제 삭제
- 전자칠판에서 한 번 눌렀는데 두 번 눌린 것처럼 들어와도 한 번만 처리해요

### 번호 뽑기
- `+ 새 뽑기` → 이름(예: 10월 자리)과 범위(1~학생 수 / 1~100 / 직접) 정하기
- **뽑기**: 학생이 자기 이름을 누르면 2초 뒤 번호 공개. 뽑은 학생은 회색 + 번호 표시
- **결과**: 번호별로 누가 뽑았는지. `선생님: 눌러서 취소` 를 켜고 칸을 누르면 그 학생만 다시 뽑을 수 있어요
- `⋯` 버튼: 결과 글자로 복사, 이름 바꾸기, 전체 다시하기, 삭제

### 수학 확인
- 월요일 아침에는 지난 금요일, 연휴 다음 날에는 연휴 전 마지막 등교일 기준이에요.
- 주말·공휴일(대체공휴일 포함)은 자동으로 빠져요. **설날·추석·재량휴업일·방학**은 우리 반 탭 "등교 안 하는 날"에 적어 주세요.
  분수 연산 마스터 교사 화면에 저장한 "등교 안 하는 날"도 자동으로 합쳐져요.
- **세지 않는 학생**
  - 마지막 단계(**L27**)를 통과한 학생(도전 216점 이상, 분수 연산 마스터의 통과 기준과 같음)은 자동으로 빠져요
  - 우리 반 탭 "수학 확인에서 항상 뺄 이름"에 적은 학생(처음 값: 전지현, 테스트)도 빠져요
  - 화면 아래 "세지 않음 —" 줄에 누가 빠졌는지 보여 줘요
- 10분마다 자동으로 새로 확인해요. 여러 기기가 같이 열어 두어도 10분 동안은 결과를 나눠 써서 분수 연산 마스터 한도를 아껴요.
- "오늘 무료 사용량이 끝났어요"가 나오면 분수 연산 마스터 쪽 한도 문제예요. 매일 오후 4시에 초기화돼요. 그동안은 마지막으로 받은 결과를 보여 줘요.

### 내보내기 · 백업
- **과제 체크 엑셀(CSV)로 받기**: 학생 × 과제 표 (완료는 O)
- **전체 백업 받기 / 백업 파일로 되돌리기**: 명단·설정·과제·뽑기 전부

### 반이 여러 개라면
같은 Firebase 프로젝트로 반마다 따로 쓰려면 주소 뒤에 `?room=이름` 을 붙이세요. (예: `https://사이트주소/?room=5-3`)

## 3. 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| "처음 설정이 필요해요" 화면 | 1-2 의 `firebase-config.js` 값이 비어 있어요. 넣고 1~2분 뒤 새로고침 |
| "Firebase 규칙 때문에 저장하지 못했어요" | 1-1 의 3번(규칙 붙여넣기 → 게시)을 다시 확인 |
| 빨간 띠 "인터넷 연결이 끊겼어요" | 연결되면 자동으로 저장돼요. 번호 뽑기만 연결 후에 |
| 수학 확인에 "반 코드를 찾을 수 없어요" | 우리 반 탭의 반 코드 6글자 확인 |
| 다른 기기에 안 바뀌어요 | 두 기기의 주소(특히 `?room=`)가 같은지 확인 |

## 4. 개발자용

```text
public/                    Vercel 이 그대로 올리는 사이트 (빌드 없음)
  index.html, css/style.css
  js/firebase-config.js    Firebase 설정값 (사용자가 채움)
  js/firebase.js           Firebase SDK 불러오기 (gstatic 10.14.1), 에뮬레이터 연결
  js/store.js              Firestore 읽기·쓰기 (과제·뽑기·명단·수학 캐시·백업)
  js/app.js                탭 전환, 실시간 구독, 연결 상태 표시
  js/views/*.js            탭별 화면
  js/lib/schoolday.js      등교일 계산 (공휴일·대체공휴일)
  js/lib/mathpractice.js   분수 연산 마스터 Firestore REST 읽기
  js/lib/model.js          명단 정리·검사 등 순수 함수
firestore.rules            Firestore 보안 규칙 (콘솔에 붙여넣기)
test/                      단위 테스트, 에뮬레이터 테스트, 브라우저(E2E) 테스트
dev-server.js              로컬 확인용 정적 서버
```

Firestore 구조 (`rooms/{room}` 아래):

| 위치 | 내용 |
| --- | --- |
| `rooms/{room}` | 반 이름, 수학 반 코드·기준, 등교 안 하는 날, 수학 제외 이름, 명단 `[{id,no,name}]` |
| `rooms/{room}/assignments/{id}` | 과제 이름, `done: {학생id: 시각}` — 칸마다 따로 저장해서 동시에 눌러도 안 겹침. `closedAt` 이 있으면 지난 기록 |
| `rooms/{room}/draws/{id}` | 범위, `picks: {번호: 학생}`, `byStudent: {학생id: 번호}` — 트랜잭션으로 중복 방지 |
| `rooms/{room}/cache/math` | 수학 결과 10분 공유 캐시 |

로컬에서 확인 (Node 20+, Java 11+):

```bash
npm install                                    # 테스트용 firebase 패키지
npm test                                       # 단위 테스트 (에뮬레이터 테스트는 건너뜀)

# 에뮬레이터까지 포함한 전체 테스트
npx firebase-tools emulators:exec --only firestore --project demo-classroom "npm test"

# 브라우저로 확인
npx firebase-tools emulators:start --only firestore --project demo-classroom   # 창 1
npm run dev                                                                    # 창 2
# → http://localhost:3000/?emulator=127.0.0.1:8080
node test/e2e.cjs                              # 창 3: Playwright 로 전체 흐름 확인
```
